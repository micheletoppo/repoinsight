\# 🔍 RepoInsight - Automated GitHub Code Reviewer via Claude



RepoInsight is an AI-driven developer utility that scans public GitHub repositories and leverages \*\*Anthropic's Claude 3.5 Sonnet\*\* to deliver architectural reviews, security audits, and code optimization suggestions.



\## 🌟 Features

\- 📂 \*\*GitHub Tree Parsing\*\*: Recursively extracts and filters primary source files via GitHub REST API.

\- 🤖 \*\*Claude 3.5 Sonnet Analysis\*\*: Analyzes system architecture, potential vulnerabilities, and design patterns.

\- ⚡ \*\*CLI Driven\*\*: Simple command-line interface with `.env` based configuration.
